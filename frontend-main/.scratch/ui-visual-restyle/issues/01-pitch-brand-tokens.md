# Pitch brand tokens

## Question

Quais tokens e lockups do pitch / pasta `assets/branding/` o app deve usar, e o PDF diverge do fly.dev?

## Answer

PDF do Downloads é deck em imagem (sem texto extraível). Tokens vêm dos lockups `assets/branding/01–06` + zip transparente (mesmos nomes). Não diverge do fly.dev.

- Accent: cobalt `#3159ED` (símbolo B)
- Ink: navy `#102D3A` (wordmark)
- Badge: lime `#DAF975` (já no tema)
- Paper: off-white `#F5F7F4`
- Slogan: *Cada etapa, um registro.* (`04-horizontal-com-slogan.png`)
- AppBar claro: `05-simbolo-azul.png` + wordmark
- Superfície navy: `06-simbolo-branco.png` watermark
- Não usar `biotracer-logo.png` (arquivo ausente)
